# MealLog

매일의 식사를 간단히 적고 날짜별·기간별로 돌아보는 모바일 우선 웹앱입니다. 설치 가능한 PWA 형태로 구성했습니다.

## 현재 기능

- 평일은 아침·저녁, 주말은 아침·점심·저녁 기록
- 집에서 먹은 메뉴마다 준비 방식과 준비한 사람(아내 또는 남편), 설거지 담당을 기록. 직접 조리와 밀키트·간편식은 준비한 사람별 끼니 수에 반영하고, 남은 음식과 배달·포장은 새로 준비한 끼니에서 제외. 같은 끼니에 아내와 남편이 각각 준비한 메뉴가 있을 때만 함께 준비한 끼니로 집계
- 평일 아침 과일주스·삶은 계란 빠른 추가
- 외식 장소·메뉴 기록, 먹지 않은 이유 기록
- 아내와 남편이 각각 먹었는지, 따로 먹은 음식, 먹지 않은 이유 기록
- 집에서 먹은 끼니의 참석자(둘 다·남편만·아내만·둘 다 안 먹음) 선택
- 저녁 식사 기록창에서만 메뉴 다음 순서로 술 종류·양·마신 사람과 음주하지 않은 날 기록
- 요약 화면의 술 탭에서 기간별 음주 일수와 주종별 총량 확인
- 요약 메뉴 목록에서는 밀키트·냉동식품과 남은 음식 메뉴 수를 제외
- 식사하지 않은 이유와 메모 기록
- B·L·D 표시 달력(평일 점심 제외). 날짜를 누르면 그날의 메뉴와 기록이 펼쳐지고, 기간별 요약에서 설거지 담당도 확인
- 술 종류·양·마신 사람과 음주하지 않은 날을 별도 탭에 기록
- JSON 파일로 기록 내보내기
- 브라우저 로컬 저장, JSON 백업/가져오기 및 기본 오프라인 캐시
- Supabase 이메일 로그인과 사용자별 클라우드 동기화(프로젝트 URL·Publishable key 설정 후 사용)

## 실행 및 배포

정적 파일 호스팅에서 프로젝트 폴더를 웹 루트로 제공하면 실행됩니다. PWA 설치와 오프라인 캐시를 사용하려면 HTTPS로 제공해야 합니다. 예를 들어 Netlify, Vercel, GitHub Pages 같은 정적 호스팅에 배포할 수 있습니다.

## 저장 방식 안내

Supabase 연결값을 설정하고 로그인하기 전까지 기록은 현재 브라우저에 저장됩니다. 로그인하면 계정별 Supabase 저장소와 동기화됩니다. 자세한 설정은 [SUPABASE-SETUP.md](./SUPABASE-SETUP.md)를 참고하세요. JSON 내보내기와 가져오기로 기록을 백업·이동할 수 있습니다.
